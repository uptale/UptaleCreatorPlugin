# Review Checklist

## Experience Structure

- Scene count matches validated storyboard or expected scope.
- Introduction and conclusion scenes exist.
- Scene names are understandable and ordered.
- Branching scenes and endings exist where required.
- Roleplay consequence scenes exist where required.

## Scene Content

For each scene, check:

- Environment type matches storyboard: photo 360, video 360, void, or see-through.
- Media is present or clearly still pending.
- Narrative purpose is represented.
- Success criterion can be implemented with available tags or manual production.
- Door/transition logic exists where expected.

## Tags

Check:

- Instruction or briefing content exists.
- Quiz questions and answers match validated content.
- Feedback tags exist for success/failure where needed.
- Branching or navigation tags are present.
- Unsupported tags from the storyboard are called out as manual or future-MCP gaps.

## Media

Check:

- Required 360 media names.
- Required 2D videos and dialogue/staging notes.
- Audio voice-over or feedback scripts.
- Images, slides, or 3D assets.
- Missing or duplicate media names.

## Reporting

Classify each finding:

| Severity | Meaning |
| --- | --- |
| Blocking | The experience cannot match the validated scenario |
| Missing | Expected scene, tag, or media is absent |
| Production gap | Asset or manual setup remains |
| Improvement | Quality, naming, or clarity issue |
