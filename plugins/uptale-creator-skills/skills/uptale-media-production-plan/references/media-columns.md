# Media Plan Columns

Use this table:

| Media type | Media name | Media description | Scene | Associated tag | Dialogue or exact text | Acting/staging for 2D video | Production notes | Done |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

## Column Rules

- `Media type`: use Photo 360, Video 360, Photo 2D, Image 2D, Video 2D, Audio, Object 3D, Slideshow, or 360 mockup.
- `Media name`: provide a clear proposed production file name when the user has not already supplied one.
- `Media description`: include what must be captured or produced.
- `Scene`: use the validated scene name.
- `Associated tag`: use the tag name or "Scene environment" when the media is the 360 scene itself.
- `Dialogue or exact text`: include exact spoken lines, voice-over, feedback, instruction text, or on-screen text.
- `Acting/staging for 2D video`: required for every Video 2D row; use "N/A" for other media types.
- `Production notes`: include format, orientation, alpha/background removal, duration, retake notes, or constraints.
- `Done`: leave as an empty checkbox or manual status marker.

## Extraction Rules

Include media from:

- Scene environments.
- 2D video persona or consequence tags.
- Audio instruction and feedback tags.
- Image and slideshow tags.
- 3D object tags.
- 360 mockups requested by the user.
- Flowchart image if it must be exported into final documents.
