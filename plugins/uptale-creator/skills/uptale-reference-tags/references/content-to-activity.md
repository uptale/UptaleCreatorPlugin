# Content To Activity Mapping

| Pedagogical content | Real situation | Recommended activity | Typical tags | Possible success criterion |
| --- | --- | --- | --- | --- |
| Simple rule or information | Brief from guide or on-site signage | Brief/information | Text, Info, Audio, Image 2D, Video 2D | Required content completed |
| Knowledge to validate | Trainer, manager, or system asks a question | Quiz | QCM, feedback, Door | Correct answer or score |
| Expected behavior | Learner faces a realistic choice | Decision | QCM/choice, Door, consequence Video 2D | Correct decision or accepted branch |
| Environment analysis | Learner inspects a real place | Risk hunt | Instruction, Markers, feedback, Door | All risks found |
| Gesture or manipulation | Learner performs a concrete action | 3D manipulation | Object 3D, Marker target, feedback | Correct object/action completed |
| Visual procedure | Learner observes ordered steps | Slideshow or procedure zoom | Slides 2D, Audio, quiz | Steps completed and check passed |
| Dialogue or argument | Learner speaks to a persona | Roleplay | Video 2D, Microphone, feedback, Door | Prompt/keywords validated |
| Time-sensitive response | Emergency or operational stress | Timed exercise | Timer, markers/questions/actions | Completed before timeout |

When the source content is too abstract, ask for the real situation and location before choosing tags.
