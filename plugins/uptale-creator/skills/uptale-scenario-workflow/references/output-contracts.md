# Output Contracts

## Framing Table

Use three columns:

| Framing element | Validated answer | AI comment or recommendation |
| --- | --- | --- |

Keep comments brief and clearly marked as suggestions.

## Pre-Storyboard Table

Use four columns:

| Pedagogical content | Real situation | Real location | AI recommendation |
| --- | --- | --- | --- |

## Storytelling

Use these labels, but write the story itself as immersive prose:

- Learner role.
- Secondary roles.
- Hook.
- Story.
- Ending or endings.

## Scene Detail

Use:

| Element | Content |
| --- | --- |
| Scene name | Scene X - Title |
| Environment 360 | Media type, staging, visible elements, ambient sound, dialogue if relevant |
| Pedagogical activity | Concrete exercise, not only the family |
| Narrative summary | Short immersive narrative of what the learner sees, does, and experiences |
| Success criterion | Condition for scene validation |

When the tag table is shown, use:

| Tag type | Tag name | Description | Options | Appearance condition | Disappearance condition | Success criterion |
| --- | --- | --- | --- | --- | --- | --- |

## Final Document Order

Final documents must include all produced and validated content without condensation, in this order:

1. Complete validated framing.
2. Detailed storytelling.
3. Visual experience map.
4. Detailed scenes with complete tag tables.
5. Success criteria.

The user must find what they validated in the conversation, in this order.
