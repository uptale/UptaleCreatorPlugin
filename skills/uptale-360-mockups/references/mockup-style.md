# Mockup Style

All Uptale 360 mockups must follow these constraints:

- Equirectangular 2:1 format.
- 360 distortion adapted to panoramic projection.
- Grayscale storyboard drawing style.
- No realistic photo style.
- No colorized render.
- Same line weight, rendering style, contrast, and mood across all scenes in a project.
- Learner camera point of view.
- The learner character is never visible.
- The environment must match the validated scene detail.

## Reusable Style Phrase

Use a stable phrase like:

`grayscale hand-drawn storyboard, clean production sketch, consistent thin black linework, soft gray shading, no color, no photorealism, equirectangular 360 panorama, 2:1 aspect ratio`

Reuse the same phrase for every scene in the same storyboard.

## Negative Constraints

Exclude:

- Square composition.
- First-person hands/body unless explicitly required and validated.
- Realistic rendering.
- Color.
- Platform UI clutter.
- Unvalidated objects, characters, or hazards.
