# Uptale Deliverables

## Core Contract

Generate final documents only after the user validates the complete storyboard. Include the full validated content without condensation. Preserve the fixed order in `references/final-document-order.md`.

This skill composes with the Documents plugin for DOCX/PDF creation and visual QA.

## Required Inputs

Before generating deliverables, ensure these are available or explicitly marked not defined:

- Validated framing.
- Validated storytelling.
- Visual experience map.
- Validated scene details.
- Complete tag tables.
- Scene success criteria.
- Global success criteria if defined.
- Validated media production plan if requested.

## Deliverables

Produce:

1. Storyboard complete document.
2. Media production plan document when media planning is requested or required.

Use Word + PDF when the environment supports rendering. If PDF rendering is unavailable, state that clearly.

## Document Quality

Use professional, readable layout. Prefer landscape orientation for large tag and media tables. Keep headings consistent and make the documents production-ready, not conversational transcripts.
