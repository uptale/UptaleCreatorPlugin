# Final Document Order

The final storyboard document must include all validated content in this exact order:

1. Complete validated framing.
2. Detailed storytelling.
3. Visual experience map, flowchart graphic only.
4. Detailed scenes with complete tag tables.
5. Success criteria.

Do not condense validated content. The user should find exactly what they validated in the conversation, cleaned up for document presentation.

## Storyboard Sections

### 1. Framing

Include the full framing table:

- Experience type.
- Training need.
- Learners.
- Topic context.
- Objectives.
- Key messages.
- Tone.
- Delivery context.
- KPIs.
- Evaluation and success criteria.
- Production constraints.

### 2. Storytelling

Include the detailed immersive narrative with roles, hook, story, transitions, and ending or endings.

### 3. Experience Map

Include only the visual flowchart. If the source flowchart is Mermaid, render or embed it as a graphic when possible.

### 4. Scenes

For each scene, include:

- Scene name.
- Environment 360.
- Pedagogical activity.
- Narrative summary.
- Success criterion.
- Complete tag table.
- 360 mockup only if requested and validated.

### 5. Success Criteria

Include scene-level criteria and global criteria if defined.

## Media Plan Document

Use the table contract from `uptale-media-production-plan`. Include the additional 2D video acting/staging column.
