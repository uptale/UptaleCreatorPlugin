# Exercise Patterns

| Exercise | Objective | Typical tags | Typical success criterion |
| --- | --- | --- | --- |
| Brief or information | Contextualize or instruct | Text, Info, Image 2D, Video 2D, Audio | Learner opened/read/listened to required content |
| Quiz | Validate knowledge | QCM, Info/Audio feedback, Door | Correct answer or score target |
| Decision | Simulate a choice with consequences | QCM or choice tags, Door, Video 2D feedback | Correct branch or acceptable decision |
| Risk hunt / inspection | Identify elements in the environment | Text/Audio instruction, Markers, Info/Audio feedback, Door | All required elements found or N of M found |
| 3D manipulation | Practice a gesture or procedure | Object 3D, Marker target, instruction, feedback, score | Correct manipulation completed |
| Slideshow / procedure zoom | Show ordered steps | Slides 2D, Audio, optional quiz | All steps viewed and final check passed |
| Roleplay | Simulate dialogue with client, manager, or colleague | Video 2D persona, Microphone, feedback, Door | Prompt/keywords satisfied or correct branch reached |
| Timed exercise | Add time pressure | Special timer plus relevant activity tags | Completed before timer ends |

## Roleplay Pattern

Use this sequence:

1. 2D video sets the situation.
2. Microphone waits for learner response.
3. Rules evaluate response through keywords or AI prompt.
4. 2D video, audio, info, or door shows the consequence.
5. Branch to good, recoverable, or bad outcome if relevant.

## Risk Hunt Pattern

Use:

- One instruction text or info/audio.
- One marker per target.
- Feedback after each marker or after all markers.
- A door unlocked by all required targets or N required targets.
